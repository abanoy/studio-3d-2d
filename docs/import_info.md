# Import info

Select a model or environment in World, then choose **Import info**. The same
action is available in the pose controls. It works in Simple and Advanced, with
both Classic and Neon. Resize the window or scroll its contents as needed.

The report separates available features, stored import data, compatibility notes,
and actions you can take. For example, it names missing textures and explains
which original lighting or physics features were retained, approximated, or left
inactive. Stored declarations do not imply that a simulator is running. Model
physics still starts off by default.

The display is read-only. Opening, refreshing, resizing, or closing it does not
change the scene, pose, camera, history, or raw import report. Packed HAS files
retain the report with the asset, so its notes remain available after reopening
without the original preparation folder. Unknown report properties are retained.

If you select another asset or change projects or sequences, the previous window
closes. An import that finishes for an earlier scene cannot add its result to the
current scene. Reports with unusually long or incomplete notes explain that more
information remains in the original report rather than claiming complete support.

This report describes the supported HAS representation. It does not certify that
the imported appearance matches the original application. Native appearance
comparison remains a separate acceptance exercise.
