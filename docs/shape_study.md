# Study deform areas inside Studio — development

In **Advanced → Shapes / expressions → Organize this control**, use **Study deform
areas**. A local Python worker compares neutral positional targets while Studio
continues rendering. Select a control to see its moved-vertex count, tentative
area, example native name/provenance and region coverage. Coverage is not a
probability, emotion classification or full native-controller certification.
Scroll to **Use suggested area** to keep a proposal. Close remains pinned.

Study never changes geometry amounts, pose/camera keys, drawings or saved labels.
Adoption uses the existing manual catalogue assignment and one Undo action;
normal Save name and area can correct it. Pending display-name input participates
in that explicit save. Existing manual choices remain authoritative until the user
chooses another area. The source asset and target IDs are untouched. Study reports
are temporary local evidence, not a new model/project format or saved inference.
Packed HAS preserves only explicit choices; a new Open has no running study/cache.

Simple retains its compact area filter and familiar labels, hiding study details.
The frozen Web preview does not contain this newer increment. Future Web builds
disable local studies; Python/native folder/process access needs Windows Studio.
The installed normal app remains the approved Model7 until a separately reviewed
update. This is current development functionality, not a normal-install claim.

## Lifecycle and data boundaries

- Apply pending amount changes and stop playback/live or queued Physics/Hair before
  starting. Refusal preserves edits and queued simulation tickets.
- Cancel is cooperative between targets/vertex batches. Closing the shape window,
  New/Open, changing the selected source or editing scene/labels invalidates old
  evidence and cancels its job. Seeking alone does not change neutral geometry.
- The UI retains its owned PID until exit, checks its actual exit code, and never
  adopts results from an invalid context. A125s watchdog stops an overlong worker;
  the worker independently checks120s/cancel markers. App teardown stops its child.
- Each job has a new guarded folder under `output/shape-studies/`, a<=1MiB request
  and atomic<=8MiB result with matching job/source SHA. Duplicate/missing/stale
  control identities and invalid example identities/scores refuse before replacing
  evidence. Unknown/unsupported controls remain accessible. Analysis folders are
  retained; quota/cleanup is unfinished.
- No live renderer objects, UI or source writes enter Python. Existing bounded
  positional decoding and conservative same-model matching are described in
  [deform_observations.md](deform_observations.md). No cloud call, game/add-on script,
  package install or source-format exporter. Native rules, normal/material/UV/bone
  effects, compound emotes and family-independent learning remain open.
