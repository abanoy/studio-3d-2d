# Import capability information candidate

Source-only proposal for the concrete IMPORT-03 reporting gap: current Source preparation puts compatibility limits in parameters.json, while the ordinary success view counts only resource warnings. This candidate displays limits on ordinary success and retains an Import info action for the selected model or map. It does not emulate unsupported native features.

No candidate has been parsed, run, adopted or qualified. The current 1084-source Full retry remains independent and unchanged.

The pure summary separates available geometry/material/rig data, retained source declarations, current limitations and recovery actions. Source/MMD/VRM producer notes remain authoritative input. Known overbroad legacy Source text is replaced only in the displayed view; every raw report field and provenance file remains unchanged. Unknown notes remain visible. Missing resources point to restoring the named inputs or choosing dependency folders and importing again. No success modal is required.

The Source preview statement is bounded to the existing five-owner profile. A report flag, retained rule count, known name or copied digest cannot enable it. The summary must receive the same actual Model instance and its actual retained report, pass existing Native.offered, then pass the complete current Native.create admission. Only the resulting scratch runner's five-chain count is inspected, and it is immediately disposed without stepping, installing, recording or modifying an actor. Unsupported contexts remain inactive with the existing actionable admission reason. This read-only probe still needs an actual qualified fixture side-effect check before adoption. The separate twelve-owner proposal is not used here.

The info editor is a distinct module and button from Appearance. One read-only instance serves Model/Pose and the World action rail, including Simple Scene mode for BSP maps. Simple and Advanced use the same summary. It retains a weak reference only while the nonexclusive info window is open, closes on selection change or busy operations, and neither stops playback nor writes authored pose, keys, physics settings or history. Plain Label text is used, so imported strings cannot become RichText markup.
