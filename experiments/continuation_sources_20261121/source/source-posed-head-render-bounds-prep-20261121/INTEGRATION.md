# Opt-in control and future shared evaluation hooks

This is a standalone control, with no automatic application to current Main. A qualification host may prepare it after the private head mesh is imported and explicitly selected: create([head_mesh]) returns a control, refresh() returns either an error or updated/statistics, and dispose() restores only owned extra-cull margins. Preparation itself writes no engine properties. The native host must retain the exact unmodified protected archive and clear both changes and helper on exit. No source-material name heuristic belongs in production activation.

For eventual integration after native evidence: capture actor-owned meshes before WorldRuntime parents child actors. Keep one control per actor, not one recursive ancestor-wide list. Refresh after Model.apply has applied current shapes/root/bones and forced skeleton transforms, covering authored editing, playback, temporary preview, live hair and Renderer final capture through one boundary. Physical body modifiers publish a later pose in PhysicsRig.capture; they require another guarded refresh after FINAL_META is updated. Avoid redundant same-state work across renderer preview/final and live-hair baseline/result evaluations. Rebuild on source-resource/bind inventory changes; do not silently accept mutable weights.

SourceShape retains custom_aabb and morph metadata. The helper reads immutable intrinsic geometry or current has_shape_bounds and independently derives a margin against the current native custom box/resource bound. It never feeds its previous output into a bounds query. Imported custom bounds and authored margins stay intact. A failed peer row changes no margins. Freed/detached nodes refuse before pose lookup; explicit disposal disconnects source watches and restores only a property whose last value is still helper-owned. An external margin edit must survive teardown.

Required next evidence, all UNRUN: exact protected two-context/four-backoff visibility matrix with the85 neutral imported targets retained; measured source/morph/pose preservation; actual transformed parent and mesh/skeleton coordinate behavior; 4/8-influence and named-bind engine geometry; negative culling control; final frame/output parity; saved close/reopen; live hair and later body-modifier lifecycle; warm and changed-pose CPU cost on the5361-vertex head and larger actors. A relative guard helps floating-point containment but is not a substitute for those measurements. Synthetic headless checks exercise only mathematical envelope and control ownership/cache behavior.
