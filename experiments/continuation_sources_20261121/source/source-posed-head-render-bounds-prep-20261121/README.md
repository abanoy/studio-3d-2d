A refresh reuses PoseBounds.palette, then computes a conservative mesh-local envelope from the current morph-input bound and current used skin transforms. The pure envelope scales the transform-box union by both measured positive weight-sum endpoints. This covers nonnegative influence sums below or above1 without renormalizing data or unnecessarily adding the distant local origin. Mixed unskinned surfaces retain their input box.

No disk reads, baking, surface-array extraction or vertex scans occur in refresh.
