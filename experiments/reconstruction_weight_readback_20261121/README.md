# Measured reconstruction weight conversion and native drift attribution

This is diagnostic evidence, not a repaired-render or whole-hair claim. Run the
public authored measurement with existing pinned Windows prerequisites:

`python -B experiments/reconstruction_weight_readback_20261121/run_packed_weight_probe.py`

The owned headless engine imports 64 authored four/eight-slot meshes from ten
rows and checks actual positive bone identities, slot counts and exact readback
bits. All260 controls pass. Six bounded solver refusals are not imported. The
source-derived normalization/truncation profile matches these actual cases;
this does not qualify all525 proposed rows, shaders, pixels or native assets.
The half-and-half split of source weight1 actually loses one packed unit.

Native attribution is a separate protected-input headless observation:10 controls
pass; 37,470 vertices/24 surfaces are compared. Of the1292 selected vertices,
1131 change aggregate imported weights. Weight-only displacement reaches48.218
micrometers; guide-palette-only displacement reaches0.126 micrometers. Original
native palettes are exact. The original48.22micrometer/165-channel-byte failure
remains adverse. No private arrays, artwork or project data are included.

The bounded solver is retained as research. Preserving integer weight mass can
still change exact sums of unpacked floats and shader accumulation. It is not
installed in the writer and is not a pixel-equivalence proof. The next repair
keeps original-weight geometry for authored rest, plus flexible geometry for
simulation and edited/baked guide poses; it must preserve materials, morphs,
bindings, lifecycle and cache ownership. The exact-zero image check stays.
