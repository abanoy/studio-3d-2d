# Minimal runtime render-bounds proposal — not implemented

## Observed path

Model.apply is the shared actor evaluation path for WorldRuntime.evaluate, Renderer.evaluate, Renderer.capture, and current live-hair applications. It applies source morphs, root transforms, live/preview/authored poses, and forces the resulting skeleton transforms. It does not publish new pose-aware render-culling bounds. PoseBounds.query is currently an on-demand framing query; its successful result does not change renderer culling.

SourceShape.apply and apply_dynamic own custom_aabb for current morph geometry. PoseBounds reads Shape.mesh_bounds, which can fall back to mesh.get_aabb. A second writer that feeds its own custom_aabb back into that fallback risks repeated enlargement. Keep intrinsic/morph geometry bounds distinct from transient posed render bounds. WorldRuntime’s child instances also have distinct actor ownership; do not recursively absorb child-model meshes when inventorying a parent.

## Smallest next controlled candidate

Before choosing a shipping writer, run a private successor diagnostic on the same protected case with a size derived from the current posed envelope, rather than the deliberately huge diagnostic margin. Use the existing PoseBounds palette and finite/bind validation, convert its world envelope back into the target mesh’s local space, and compare two bounded controls: (a) a transient custom_aabb equal to that posed envelope, and (b) extra_cull_margin derived only from the distance needed to enclose that envelope in the intrinsic/morph box. Retain native baseline and restore both properties after every cell. Record containment and timing scalars; preserve all existing camera/material/pose controls. This distinguishes the appropriate engine-facing property without claiming that a large margin is the repair.

## Proposed production shape if the controlled candidate passes

Add a small per-instance runtime culling helper owned by Model. Capture each actor-owned mesh, original custom_aabb and extra_cull_margin before child actors attach, along with an explicit intrinsic mesh-space bound that never reads the helper’s previous output. For morph meshes, consume SourceShape’s current has_shape_bounds as the input bound. Keep source/morph metadata and saved model data unchanged. Avoid character names, material-name guesses, automatic model conversion, and a fixed global padding constant.

Reuse/refactor PoseBounds.palette and its bounded conservative envelope calculation as a pure per-mesh function taking an explicit intrinsic/morph input AABB. For a changed palette/morph state, obtain a finite local posed envelope, merge a small relative numerical guard with the original bound contract, and publish only the property selected by the controlled candidate. The existing conservative path transforms a bound with each skin palette entry; it needs no per-frame vertex scan. Do not assume that current conservative union alone is a proven render envelope: ArrayMesh UNORM16 readback can have nonnegative influence sums below or above one, while PoseBounds accepts an absolute sum error of up to .001. A weighted point can then leave the union of individually transformed boxes. At inventory time validate actual immutable weight arrays and cache proven per-mesh weight-sum limits. In mesh-local coordinates, a conservative construction can include local zero with the transformed-box union and scale the envelope using a proven maximum sum at least one; prove this calculation, including zero/invalid sums, rather than normalize source weights or rescan them every tick. Require explicit tests for 4/8 influences, sums below/exactly/above one, boxes offset from local zero, named binds, parent/mesh/skeleton coordinate transforms, and morph extremes before relying on containment for culling. The existing exact per-vertex framing query remains the independent correctness oracle, not the hot path.

Refresh after skeleton updates at the end of Model.apply, covering authored editing, playback, temporary preview, live hair and final capture through one path. Physical body modifiers may produce a later final pose; refresh that actor again from PhysicsRig.capture after FINAL_META is published, with valid tree/owner guards. Do not query during teardown. On stop, dispose, reimport, or inventory change, clear or restore only helper-owned transient state, then recompute for the current authored pose. Do not freeze simulation or write keys to refresh a bound.

## Performance and correctness gates

1. Build immutable mesh ownership/bind information and validated weight-sum limits once. Cache geometry-dependent envelopes; compare current palette/morph signatures before recomputing and skip redundant same-state evaluations. No disk I/O, mesh baking, full surface-array extraction or per-vertex skinning in the frame/tick path. Keep the existing 512-bind limit and explicit finite/budget errors. Count cache hits, changed mesh updates and palette operations in synthetic tests. A helper must not silently rescan an arbitrary hierarchy or every ancestor for every child actor.
2. Avoid redundant work during Renderer.capture’s preview/final evaluations and 120 Hz live hair’s baseline/result applications. Measure rather than assume that signature construction is cheap. Compare unchanged-frame and changed-pose costs on the protected 5,361-vertex face mesh, synthetic multi-mesh rigs, and larger native actors. Set a release budget after the baseline measurement; report any slowdown.
3. Prove that successive identical evaluations do not enlarge the box, produce new mesh/material resources, or change source hashes, custom morph metadata, instance separation, history, drafts, keys, lighting, or shot values. Shrinking to a later smaller pose must work rather than retain an ever-growing union. Invalid/freed nodes must leave no teardown errors.
4. Synthetic GPU tests must demonstrate an actual culling failure with geometry outside its bind box, corrected visibility with a derived bound, and continued absence for geometry truly outside the camera frustum. An always-visible/global-margin workaround must fail the negative control. Independent engine-baked geometry must remain enclosed under rotated/scaled parents, morphs, named binds, and 8-weight meshes.
5. Privately repeat the forty-cell protected comparison after the candidate; the six close baselines should retain the face without material, clip, or huge-margin changes, and the two previously visible far baselines should stay unchanged apart from any explicitly measured numerical raster effect. Add final-frame capture parity, save/close/reopen, live hair on/off and body modifier lifecycle checks. Keep fixture imagery and transform data out of public packets.

This proposal is separate from the UI/camera adoption and Summer Sakuya percent/native amount UX. No current-source replacement or implementation approval is implied by the diagnostic result.
