The one-shot builder rejects changes or an existing destination and writes a deduplicated deterministic gzip archive. Original files are retained unchanged. The artifact-only verifier is independently implemented and never imports the builder/checker or reads originals.

The source checker preserves all three exact check ledgers, all6 native labels, unit34, raw VRM9,8 physical jobs, available height argv bindings and recorded scope/source preservation. It explicitly does not fabricate missing catalogue/comparison argv or a headless private receipt. Original arrays/models/media and generated native/request/plan files are excluded; only bounded derived measurement metadata remain in results.

Admission CPU tests mutate valid metadata coherently in RAM. Source/artifact tests and archive construction perform no engine, CIM, Git mutation, conversion or upcoming-full reads. Native behavior observed by the completed focused runs remains separate from full verification, native-fidelity, merge and owner acceptance.
