The smallest product increment is explicit, temporary simulation of the original qualified Junko `FrontHair1` joint through the existing `Secondary` lifecycle. Keep every other model on its existing VRM/HAS helper backend.

## Runtime attachment without asset or body replacement

Keep `PhysicsEditor.simulations[id] is Secondary`. Extend `secondary_live.gd` with an optional native runner alongside its optional generic `runner`; keep `primary`, `bodies`, `initial_pose`, `initial_world`, `latest`, `capture_pose()`, `root_transform()`, `detach_primary()`, `stop()` and `dispose()` contracts. A native runner borrows the existing actor/skeleton and owns numerical state only. Enabling it must not call `prepare_model`, `restore_world`, `SceneIO.load_glb`, the helper generator or `Rig.create`; none is needed to rotate a verified existing skin bone.

Add a backend-neutral `driven_ids()` on `Secondary`. Both overlap checks in `PhysicsEditor` currently walk `simulation.runner.chains`; replace those two accesses with this method so native-only wrappers need no fabricated VRM chain or generic tail. Preserve generic chain/collider behavior and its existing wind grouping. Distinct backends must never write the same HAS bone ID. For a first narrow increment, native-only operation is sufficient; generic models and independently simulated actors retain their existing paths.

An already-running body is borrowed ownership. Admission failure must leave the same body solver, simulator node, bodies dictionary, physical nodes, velocities and running state in place. Do not stop/recreate it to obtain a clean skeleton. The accepted native8 compat3 harness permits the exact empty imported modifier only; the existing ragdoll instead installs active physical bones and a full cached final palette. Therefore require body Physics off for native mode on that actor until a separate modifier/weighted-palette/Record test qualifies their combination. Check this before any live-pose assignment or `Rig.create` call. Likewise, refuse enabling body Physics on an active native wrapper before constructing a new body; keep the native preview running unless the owner explicitly turns it off. Generic HAS hair+body combinations continue to use the existing borrowed-primary path.

Use simulation age/fixed time, not wall-clock time. The current fan field already includes deterministic gusts, falloff and a bounded world force; do not invent hidden extra random jitter.

## Off, failure and operations

| Trigger | Required native behavior |
|---|---|
| Hair & clothes Off | Existing `disable_hair`: detach primary ownership first, dispose only secondary state, clear live/preview offsets, apply authored current frame. No model-data write or new key. |
| Native solver/admission error | Clear native transient output and restore authored pose; preserve an existing borrowed body. The current `_physics_process` error branch calls `freeze(id)`, which authors the simulated pose, so native failure needs a restore/discard branch. |
| Seek, Save, export, playback, pose edit | Quiesce native preview through Off semantics before the operation. Current `freeze_all()` calls `freeze(id)`, which writes `actor.data.pose`/`draft_frame`; do not silently save an unrecorded native deformation. Finish an explicit Record normally. A remaining body may retain its established explicit freeze behavior after hair offsets have been removed. |
| Record | Use the existing locked Local/World target scope, `capture_pose`/root transform sampling, rational frame interpolation,1MiB/2048-key budgets, atomic range replacement and Undo. No separate native animation storage. |
| Record Stop | Existing `finish()` saves ordinary FK keys and turns simulation off. `WorldRuntime.restore_instances` changes authored data without replacing source/root/skeleton. Unrelated clips, shapes, root channels, contacts and peers remain protected by the existing path. |
| Record Escape / invalid context | Discard the take through the existing cancellation path and restore authored state. Never install partial unsupported native output as a frozen draft. |
| Undo, source replacement, document/world teardown | Dispose numerical state before actor replacement through existing clear/generation/asset-change handling. Cancelled asynchronous setup must not dispose a primary still owned by the editor. |

`Secondary.create` currently assigns an initial live pose before awaiting generic spring setup. Preserve the existing pending-generation/root/data transaction guard, and restore the prior live ownership on every new native failure. An optional native-only constructor can be synchronous; do not bypass cancellation/context checks simply because it needs no render warmup.

Root's selected first route is the existing explicit Hair & clothes On action on an exactly admitted original asset with no generic chains, rather than an additional Advanced checkbox. Describe its partial scope in the tooltip/message: “FrontHair1 ·1 imported joint”; do not imply all49 retained rules are simulated. Runtime intent remains per actor/source identity; import intents, HAS Open and Undo must not automatically activate this experiment. Fan aiming/status uses admitted native anchors only when generic chains are absent.

Retained metadata stays immutable: `source_jiggle.applied=false`, `full_native_rule_layout_verified=false`, crosswalk `native_solver=not_implemented`, and the `bound_inactive` resolver contract describe source provenance, not a toggle. Record current runtime activity in the simulation/UI only. A packed or linked HAS stores the original standardized asset/report and ordinary authored/recorded keys; no numerical state, clocks, tip velocities, scratch nodes or automatic restart intent is serialized. Cold-open restores the saved keys with Hair & clothes off.

Important same-actor boundary: helper Apply writes a derived GLB and replaces `row.source`/`sha256`, while retaining the original native report. The strict resolver correctly rejects that derivative because its asset SHA no longer equals the authenticated crosswalk GLB. Keep such actors generic. Same-actor generic+native coexistence later requires authenticated derivative bindings plus disjoint ownership; checking only disjoint IDs or ignoring source SHA is insufficient. Native mode can operate on the original qualified GLB without generating helpers.

`WindReview` and `PendingHelperWindPlayer` currently instantiate `Spring` directly on a disposable derived candidate; `WindReview` even builds candidate metadata containing shapes only. Their “Try a local blow” path therefore does not validate/preview the native backend. Initially identify that review as configured-helper preview and keep it out of native mode, or add a separate backend-aware route that retains exact provenance and labels its scope. Do not replace/hide the running original body as a way to activate production native physics.
