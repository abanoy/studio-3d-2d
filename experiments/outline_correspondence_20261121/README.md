# Outline correspondence proposal

This is a read-only, protected-fixture analysis. No candidate was built or applied.
SAFE_FINDING.json contains counts, hashes and limits; the original-index masks
and artistic data remain local. It is not a full-hair qualification.

diagnostic_source.py.txt preserves the exact executed analysis source. It was run
from the primary checkout's output directory with the existing neighboring
reconstruction checkout and original protected Junko GLB. Those explicit paths
and matching source/helper hashes are prerequisites, not bundled inputs. To
reproduce, restore that layout and copy this diagnostic text to the original
output/analyze_outline_correspondence_20261121.py path. The named result directory
must not already exist. The script refuses existing output and writes private
original-index masks only under output. Do not publish that generated private file.

Matching uses exact UV and native joint/weight identities plus unique nearest
position/region and corresponding triangle classes. It does not weld positions
or infer groups from material names. Distances are mesh-local source units.
One unmatched vertex and six unsupported triangles remain unresolved; incident
vertices are quarantined. A mixed front/back connected component cannot be
included by flooding its entire surface.

Pairing reviewed masks with each colored component may reuse its guide set.
Naively adding outline points could exceed the current 4,096-row surface-contact
budget, so adoption also needs an explicit physical-surface/correspondence design.
No budget, weight, mesh, collider or clearance threshold was changed.
