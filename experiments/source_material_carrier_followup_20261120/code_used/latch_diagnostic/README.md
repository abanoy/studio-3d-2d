# Safe carrier latch failure diagnostic

Authored source and synthetic tests only; no execution by this author. This is separate from the closed-V5 publication and the immediate V6 absence-probe run, which retain carrier 3325.

The helper keeps the original export operation, owned attributes/scene/selection/addon restoration and bounded output handling. On failure only, it reads the owned session/latch instance fields and records a fixed known H 636a call-site stage plus an allowlisted exception category/count. It never copies the SDK RuntimeError string, object representations, filenames, private type names or values. Unknown stage/shape/count stays generic; unknown exception categories become OtherError. Missing/never-created session/latch remains explicit.

The original exception object is re-raised. Diagnostic failure cannot replace it or bypass the existing finally cleanup. A diagnostic is not a success, resource, native/fidelity or adoption gate. No hook/cache/source/image policy is relaxed and no original or installed tool is modified.
