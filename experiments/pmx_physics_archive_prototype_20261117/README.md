# Inert PMX physics archive prototype

This is a working source and synthetic CPU increment in a new experiment folder. It changes no production importer, project format, simulation, Review source or existing sealed packet. No artist file, Blender/Godot process, live full-run output, process observer, network or Git operation was used.

`pmx_archive.py` accepts immutable RAM bytes for a GLB, an authored PMX source and its equal copy, plus an explicit source byte length/SHA256. It invokes the exact copied raw reader from sealed `9946bf2b`, keeps its `UNQUALIFIED_SOURCE_CPU_ONLY` capsule, and embeds its exact canonical UTF8 JSON text in the separately versioned `asset.extras.has_native_physics_archive` envelope. The archive contains opaque source declarations; it does not translate units, names, bodies, joints or raw words into HAS behavior.

The result contains three values: new GLB bytes, a report preserving all existing report fields plus a small descriptor, and a capture provenance record. The descriptor carries location, capsule checksum/length, provenance checksum and explicit unsupported/unqualified status. It does not contain the capsule, source path, source SHA, names, raw words or table data. `extract()` requires the descriptor and an independently retained expected provenance record, then returns the exact capsule bytes. Retain that provenance separately; taking a replacement expected record from a modified envelope would not establish integrity.

Only authored fixture bytes are exercised here. Matching provided original/copy buffers is not a filesystem-copy or native-file witness. The reader is not an independent oracle; its source SHA and the capsule SHA do not qualify its table-location interpretation. The native-read qualification protocol, stable readonly input wrapper, independently frozen oracle, owned resource runner and input-specific witness remain unimplemented. A caller must not use this experiment as native admission.

The GLB profile requires version2 and exactly JSON then BIN, matching the existing helper workflow's narrower structure. It preserves the exact BIN payload including padding and all unrelated typed JSON members, including integer/float distinctions and floating signed zero. JSON spelling, member order and padding may change; this is a newly derived GLB with a new checksum. Tests author a one-pixel PNG in RAM from fixed bytes and zlib to check an embedded image's exact encoded bytes; no artist image is read or any image decoded. This experiment does not validate a complete glTF model.

The assembler refuses duplicate JSON keys, invalid UTF8, NaN/Infinity and exponent overflow, non-JSON report values, occupied archive/report slots, unsupported extras types, extra/truncated/misaligned chunks, source/copy/provenance differences and insufficient capacity. It never removes a field, installs an empty capsule or falls back to a successful unsupported result. All operations return new RAM values; refusal cannot modify original bytes, an earlier derived artifact or the caller's report.

Hard ceilings are2MiB canonical capsule,16MiB whole escaped/padded GLB JSON,128MiB whole GLB,256KiB whole preparation report and1MiB separately checked project metadata. Exact integer overrides can only lower those ceilings. Tests use smaller exact/one-byte-over capacity boundaries, plus a64-instance synthetic metadata example containing descriptors rather than capsule copies. These are byte acceptance caps, not measured peak-memory, wall-time, Godot import, helper derivation, HAS packing, cold-reader or compatibility guarantees. No installed helper or production consumer was run.

From this folder run `python -B -m unittest -v test_archive test_native_reader test_full_prefix`. The original reader, authored fixtures/manual oracle and all33 regression methods are exact source copies. The first combined run passed47/48: one new test incorrectly expected mask65535 from the default authored32769 fixture. `history/attempt1` preserves that failure, tool output and source snapshots. The corrected test asserts32769 and separately authors a65535 source word; it does not change the reader or relax a predicate. Final CPU results and source identities are recorded separately.

The library imports only its copied raw reader and Python standard library. Use this exact sealed source folder/import graph; the descriptor's reader digest is a source-binding declaration, not a security boundary against a substituted Python module. No command in this packet opens a native path, invokes preparation, activates a runtime or publishes an artifact.

Remaining integration work includes actual qualified native input, a source-to-owned-copy witness, independently qualified table agreement, a real helper derivation preserving the envelope, old/current linked/packed/project/asset-package save and cold-open checks, actual resource/capacity measurements, and a reviewed opt-in production preparation policy. Native simulation, bone crosswalks, physical validity, scale normalization, repair and adoption remain unsupported.
