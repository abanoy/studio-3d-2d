# Selected-MDL capture and final recheck draft

This is an output-only pure-Python helper for a future optional inert native metadata seam. It does not change the reviewed raw reader or metadata adapter, production code, original inputs, SourceIO, caller paths, main source/doc/test files or Git state. The current canonical remains the sole app/runtime/graphics owner. No native model was used in these CPU checks.

`source/source_mdl_snapshot.py` exposes two small actions:

- `capture_selected_mdl(absolute_original_path)` returns a frozen `MdlCapture(file, raw, native_sha256)` or frozen `NotInspected(reason)`. Raw data is immutable `bytes`; the SHA is independently calculated from those bytes. `FileSnapshot` records the exact supplied path, byte length, nanosecond mtime, device and file identity. Capture admits at most16MiB, regular non-reparse files with observable identity. It does not parse MDL headers.
- `recheck_selected_mdl(capture)` independently reopens/rechecks the same path, compares handle/path identity before and after the bounded read, rehashes the new bytes, and requires equality with the captured bytes/hash/stat. Success returns `None`. Captured-source inaccessibility, replacement, byte change or unverifiable read is always `SourceIdentityError`.

Initial missing/unreadable/unsupported/oversize input returns only a bounded reason. `NotInspected` has no native SHA field and cannot be supplied to the final recheck as a capture. An open failure after a supported initial stat is classified initial-unreadable only if a fresh second path stat still matches exactly; disappearance/replacement is an integrity error. Once a stream opens successfully, short reads and read/fstat/poststat errors never become optional budget fallback. These are observed file identity/consistency checks, not a claim to prevent an adversarial source from transiently changing and restoring itself between all observations.

The caller must keep its original SourceIO path unchanged. The mandatory original/container SHA guard stays upstream and remains distinct from this selected native MDL hash. Capture should occur before SourceIO reads the selected MDL. If capture is not inspected, preserve ordinary static conversion and report its explicit reason without fabricating native identity or exact values. For a real capture, feed only its immutable bytes and independent native SHA to the optional reader, then call the final recheck immediately before publishing optional metadata. An integrity error must escape the optional-format/budget omission path and refuse publication. This draft defines its own `SourceIdentityError`; integration must deliberately catch/propagate that type alongside the reviewed metadata adapter's identity error rather than treating either as unsupported metadata.

There is no sidecar API, no output-file writer, no solver, no automatic Hair & clothes, no body/controller binding and no actual Blender report-fit or adopter claim. Selected native MDL capture size16MiB is an optional-read admission bound, separate from metadata128KiB and final parameters256KiB budgets. Large inputs keep the ordinary static SourceIO path available; they do not get a fabricated metadata proof.
