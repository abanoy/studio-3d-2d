## Actual ordinary UI and important limits

`pose_editor.shape_button` opens `shape_window`; `animated_shapes` is the “Shape at this frame” editor. Amount is a SpinBox. It is not a raw mesh channel setter. In Simple, area/search span all parts; choose an item by **both** `result_nodes[i]`(original GLTF source node) and `shapes.get_item_metadata(i)`(target index), then require its exact native name. Display labels alone are insufficient. Keiki `Tools` is explicitly estimated as Accessories/Tools; Mima `ah 1`, `ah 2`, `EEEE` are explicitly estimated as Mouth. These are discoverability labels, not semantic or geometric proof.

Use attached controls: press `shape_button`; select the area filter and emit `item_selected`; set search text and emit `text_changed`; select the exact ItemList row and emit `item_selected`; set `amount.value`; press `apply_button`. Observe effective values and geometry afterward. Never author with `MeshInstance3D.set_blend_shape_value`, direct metadata replacement, `set_shape_amounts` or a direct curve injection. `shape_ui_actions.gd` is source-only helper text for those attached controls; it has not been Godot-parsed or run. Signal-driven control tests exercise the ordinary handlers, not physical pointer hit targets or owner usability.

Each Apply is one selected binding and one history action. There is no arbitrary multi-select/batch amount editor. A changed amount with Auto-key on writes an independent shape key; Auto-key off makes a frame-local draft until Record. There are independent camera/body/shape channels. Normal authoring handlers freeze existing simulations, so these first cases require all Physics/Hair&clothes/live motion off; they do not certify simultaneous live-body/peer physics behavior.

“Use imported shape” is **not** a global morph Off switch. It zeroes declared imported defaults underneath explicit base adjustments; authored sampled values still replace their channels. The native defaults here are all zero, so Off can legitimately produce no pixel change. Verify the saved flag/history and preserved authored values. “Use base amount here” resets one current-frame value; “Use all base amounts here” batches only already tracked channels. “Preview this control…” offers a true all-deforms-off neutral render only in its isolated disposable model, without changing/saving project Off state.
