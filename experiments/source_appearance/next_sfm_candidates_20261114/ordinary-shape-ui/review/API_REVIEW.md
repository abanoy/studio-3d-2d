## Review findings and execution preconditions

1. **Linked sidecars are conditional, not automatic.** `tools/has_project.py:410-426` externalizes a linked reference beside the HAS file only when the resolved source is inside the configured `cache_root` or `cache_roots`. Saving linked while an arbitrary fresh test-input GLB is readable can retain that input as its reference. Offlining it would correctly make cold Open refuse. The strongest proposed sequence is packed Save, terminate writer, fresh packed Open (empty origins, cache-root source), linked Save, verify the resulting linked header/reference/sidecar SHA, and only then offline the owned input alias. Keep every referenced sidecar. `src/has_snapshot_writer.gd:40-60` prefers a valid origin when present; merely having an in-memory/cached actor does not prove a linked save is independent of its original input.
2. **The helper does not select a part in Advanced.** `choose_exact()` verifies the tuple against all `editor.rows()`, then searches the current ordinary list. Simple mode searches across parts when text is nonempty; Advanced and base-shape editing search only the selected part (`src/base_shape_editor.gd:114-145`). Before the Advanced base EEEE edit, select the part whose `parts.get_item_metadata(i)` equals 231, with the ordinary `parts.select(i)` plus `parts.item_selected.emit(i)`. Do not set `node_index` directly. If only one shaped part exists the draft can work, but that must be observed rather than assumed. Its current failure mode is safe refusal.
3. **Action helpers do not establish successful mutation.** `apply_amount()` and reset helpers return after emitting a signal; handlers can refuse because of simulation freezing, invalid bindings, geometry budgets or metadata limits. The caller must await settling, reacquire/select the actor, and assert exact resulting data, amounts and intended history delta. Values are also subject to SpinBox bounds. Proposed amounts .15/.2/.5/.8 are inside both the UI range and the parent-observed native 0..1 controller ranges, without proving native controller evaluation.
4. **Off needs an On precondition for a one-action assertion.** `imported_defaults_off()` silently does nothing if the CheckButton is already false. Assert the starting saved flag and UI state are true, then verify the actual transition, history and preserved authored values. Do not emit a duplicate toggled signal after changing `button_pressed`; normal assignment already emits the connected signal when it changes.

The rest of the proposed sequence is consistent with the inspected source, subject to the execution gates and assertions below. No blocking application defect is established by this read-only review.
