optional skin/bodygroup controls in the ordinary Source import dialog. Defaults
still omit an override; explicit invalid/all-hidden choices cannot silently fall
back. Member/reset/cancel/timeout and actual process ownership are exercised.

not native conversion/adoption or a new full aggregate pass. Wider native cases
and real conversion/persistence remain next. Both earlier actual UI passes are

headless source/test snapshots are historical checkpoints; raw hashes distinguish
them. Every graph job stays on run.command private Windows desktop.

engine's process-map kill removes the retained entry/closes native handles even

consumes that retained entry once and never retries or reaches genericPID kill.
This bound does not certify another engine/platform or a universal Windows launch
race fix. Primary references are in the current main benchmark.
