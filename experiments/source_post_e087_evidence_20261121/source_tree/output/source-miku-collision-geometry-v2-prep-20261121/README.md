# Independent Miku segment and skinned-vertex clearance — source only

This pure GDS helper measures contacts; it does not respond to collision, bind a model, load files or change a pose. The separate saved-case probe supplies actual raw solver pivots, actual raw-FK pivots and final visible-FK pivots. After the same actual poses are applied, a Root-owned harness may decode the exact private Miku POSITION/JOINTS_0/WEIGHTS_0/inverseBind rows and use skin_vertex with genuinely bound current jointWorld×sourceInverseBind transforms. Calibrate the rest frame against PRIVATE_RUNTIME_ALIGNMENT first; do not assume a correspondence from names or compare an unrelated geometry stream. Retain the actual989 hair-support row identities in RAM only.

measure(pivots,radii,deformed_hair_vertices,world_capsules) returns only counts/minima/finite scalar scope flags. It includes point/capsule clearance, a conservative whole-segment max-radius envelope, and actual deformed hair-vertex/capsule clearance. These are additional independent measurements beyond particle tips; they are not body triangle contacts, swept collision, or proof that the GPU skin/shader uses the same bound frames. Surface-interior/edge/body-mesh contact remains an additional qualification if the capsule approximation is insufficient. Never relabel the lower sleeve capsule's11 initial hair overlaps as a corrected clean start.

Input counts and numeric coordinates/radii are bounded. Skin rows use exactly four actual slot indices and original finite positive weights; accepted small weight-total roundoff is retained without normalization. No nearest-point mapping, weight repair, source-basis repair, cloth reconstruction or output arrays are implemented.

Copy the module to res://src/secondary_collision_geometry.gd and the unit to res://tests/secondary_collision_geometry_unit.gd in a fresh owned snapshot. The26 authored controls independently cover crossing/parallel/collinear/point segments, two-joint linear skinning, unnormalized small weight drift, malformed bindings, immutability, and a concrete case where both tips clear the arm capsule but the intervening segment and one hair vertex penetrate it. The unit has a10second SceneTree watchdog; Root's process timeout and exact input/source/closure guard are also required. Author executed no tests/native/GPU. No application adoption or actual contact qualification.
