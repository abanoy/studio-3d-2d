The worker binds actual native Material/BodyPart/Model/Mesh refs and new
non-evaluated Blender Object/Mesh/Material IDs. It checks the native

every ordered polygon material index, native skin-cell refs, stored Object
skin-property refs, returned container/bodygroup ordering and the blank None
entry. New-material inventory must contain exactly the observed placeholders.
References are not reconstructed from equal names, coordinates or an old B
snapshot. The actual source's string fallback was not taken; its behavior is
covered only by fabricated CPU tests in this packet.

The existing full-module compiler attestation and attribute-exact AST inverse
remain mandatory. The original normal setter and validate call run unchanged,
with only the existing four observation boundaries. The material observer adds
reads, not setters, material rebinding, skin switching or a second import.

For each used raw MDL mesh material field, the cold binder independently checks
both integer domains and `skin_families[0][raw] == raw`. All four used fields
passed for this family. SourceIO directly indexes the texture table with the
raw value; nonidentity default rows refuse without repair. Alternate skin rows
need not be permutations. This is explicit integer-policy agreement, not an
MDL49 engine-renderer proof. The binder's row digest is over little-endian
uint32 words; the earlier preflight digest remains its own producer's evidence
and is not asserted to use that same byte encoding.
