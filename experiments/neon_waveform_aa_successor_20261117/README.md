# Waveform edge AA expectation, source-only successor

The failing first transient is clamped to a selected clip's fractional left edge. The previous opaque-border expectation is incorrect there. Product appearance stays unchanged. This successor preserves all 13 original checks, the Classic `467d45` binding, all four transient bars, the same nine-pixel neighborhoods and the `.02` RGB tolerance. It retains the compact Audio-row reveal and bounds check and adds one rendering-contract check: 15 checks total.

Godot's [fixed 4.6 source](https://github.com/godotengine/godot/blob/4.6-stable/scene/resources/style_box_flat.cpp#L550-L573) creates an outer AA strip with transparent color at `L-a/2` and border color at `L+a/2`. The straight-edge alpha is therefore `t=(pixel_x+.5-(L-a/2))/a`. The [header defaults](https://github.com/godotengine/godot/blob/4.6-stable/scene/resources/style_box_flat.h#L43-L50) set AA size to one and border blending off. This is vertex-color interpolation, not an assumed area-coverage estimate. Corners and overlapping infill require different geometry and are refused here.

The [Compatibility shader](https://github.com/godotengine/godot/blob/4.6-stable/drivers/gles3/shaders/canvas.glsl#L245-L259) interpolates those colors; [mix blending](https://github.com/godotengine/godot/blob/4.6-stable/drivers/gles3/rasterizer_canvas_gles3.cpp#L686-L692) uses source alpha. The [Khronos reference](https://github.com/KhronosGroup/OpenGL-Refpages/blob/main/gl4/gl_FragCoord.xml#L26-L46) defines default half-pixel centers and identifies the multisample exception. Thus the predicted edge color is `BAR.blend(SAVED with alpha=t).blend(wave)`. The interior formula remains `BAR.blend(fill).blend(wave)`.

The candidate derives `L` from live control geometry and uses the actual style's AA size and border color. It never reads pixels to choose an expectation. Before using this restricted oracle it requires the pinned runtime prefix, unit transforms/oversampling/interface scale, disabled pixel snapping/MSAA/HDR/transparency, the source style contract and a straight-edge sample outside the infill. Unsupported conditions fail explicitly; they do not weaken the assertion.

Native validation is pending. CPU tests establish the closed form against independent triangle interpolation and prove that missing edge/interior transients cannot satisfy this color predicate. They do not qualify GPU rasterization. The first 9775 failure and all earlier Classic/native receipts stay untouched. The initial preparation refusal is retained: a checker counted lines rather than balanced check calls, then was corrected without changing the candidate.
