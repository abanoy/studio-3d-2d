# Contract before hidden main-view integration

The implemented gate ends at imported bindings/base state. It does not publish a replacement model into a live Studio scene.

1. At an idle target, capture the actual actor identity/root instance, generation/revision, authored source hash, current frame and reviewed static shape settings. Preserve authored data, camera/selection/history/dirty/recovery state. A changed actor/source/frame/edit/shape must invalidate the prepared request.
2. After the existing owned worker is fully reaped and its result admitted, import the exact checksum-bound candidate into a fresh hidden owned root. Capture the actual full source-node inventory and actual kind/ID/local/global/parent snapshots. Apply the same complete gate; do not construct its tables from the receipt alone.
3. Use the gate's original source-node keys to translate original bone IDs to candidate bone IDs. Original bone deltas remain relative to the verified imported base. Reject any authored bone key without an explicit source-node join, including any unexpected importer-created runtime bone. Preserve actor-root transforms separately. Node references use actual paths; offset references use their explicit parent bone and verified local offset. An added offset endpoint is not a new rotating bone.
4. The current proof covers static imported/default/explicit morph values. Live animated shape evaluation, currently deformed pose state, active body/contact/ragdoll state and arbitrary controller callbacks require separate integration evidence. Do not infer their compatibility from neutral-base equality.
5. Rebuild the candidate's loose-part catalogue from its real configured source nodes, helper endpoint identities and weights. Bind any temporary group identity to the candidate hash. Never pair groups by labels, row order or chain count. VRM0/VRM1 native retained chains were imported completely here, but new helper derivation was explicitly not proved for those two bundles.
6. Only after these gates pass may an isolated hidden preview replace the original representation transiently. Stop, cancel, close, late result, stale owner or any failure must restore the original representation and release owned work. Existing Apply/install with its authoring/Undo contract remains a separate operation.

A later private-desktop graphical probe should first prove the original posed model remains visually/structurally unchanged while hidden candidate preparation runs, then prove Stop/error restoration and stale-result refusal. Full main UI/body interoperation remains untested by this packet.
