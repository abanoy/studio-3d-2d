## Inputs, output and preservation

The wrapper reads original prepared assets and parameter reports only. Graphical
mode stages exact hash/size/ns-mtime copies inside its own run before the backend
creates the Back hair candidate. No extraction, new runtime download, Steam
mutation or installed-app replacement occurs. Original GLBs/reports are checked
again afterward. Generated source GLBs, a tiny known-tone WAV, packed test saves,
PNGs and logs stay private under this prototype's `gpu-verification/<nonce>`.
No artwork is uploaded.

Every job requires zero assertions/engine errors and a receipt with exit0,
confirmed private child desktop, no foreground child, closed job and closed
desktop. The driver records all prototype source hashes/sizes/ns-mtimes before
and after, all nine frozen runtime hashes, exact harness hashes, original input
identities and fresh root context. Partial per-job progress and failures remain
retained. The prototype emits no updates to canonical verification pointers.

The lifecycle job exercises the real PNG timeline export in both warming/running
states. It compares exported frame1 against the original native render. No extra
movie is rendered; the original 1080p24 movie/helper/physics/readback regressions
remain separate required checks before a source port can be promoted.

## Explicitly unproven

- None of the new graphical assertions, input routing, actual motion, pixels,
  timings, node cleanup or exported frames has run yet.
- Headless cursor-return signals do not certify physical cursor movement or
  artist comfort on the owner's desktop. Private synthetic key input does not
  close device/novice/artist gates.
- Native self-replay is not source-appearance approval, native JIGGLE equivalence
  or compatibility with every skin/bodygroup/assembly feature.
- Pending single/batch helper setup preview before Apply is phase2, outside this
  declared-chain controller. Persistent Hair & clothes exclusions are separate.
- A native asset whose valid chains are linked may have one inseparable group.
  The procedural case supplies the independent/excluded positive; the native
  report records actual availability rather than inventing independent groups.
- Ordinary movie export is serial; no concurrent/nested-capture support is claimed.

The harness may reveal implementation or fixture defects on its first actual
run. Preserve those failures and fix the demonstrated cause; do not weaken
original helper/physics assertions to make this proposed matrix green.
