This compact archive retains two completed scoped runs: the instrumented original

revised fixture passed all106 checks and its independent unit passed12830 checks
across144 cases (wrapper14.1473874 seconds, exit0, reaped). This is no canonical

Every admitted original text/source byte is retained in a deterministic gzip
object. BINDINGS.json maps complete original root/path, hash, byte count and
read-only captured mtime to those objects; duplicate originals share an object.
INDEX.json hashes compressed and decompressed bytes. No original is overwritten
or deleted. Source/scalar RGB values are small diagnostic measurements, not image
or model payloads. PNGs, GLBs, media, preferences and native geometry are excluded.

the four raw display/base/composition measurements. The successful ordered engine
log keeps106PASS results. Removing only the four newly named composition checks
leaves the exact original102 ordered semantic messages. Raw engine logs and
combined captured stdout/stderr are preserved as distinct artifacts; concatenated
streams are not used to invent event ordering. Unit and smoke ordered engine logs
are retained separately.
