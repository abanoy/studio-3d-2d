## Object timing fixture input correction

The original smoke scrolls the complete timeline content to its end (`scroll_vertical=2000`) and then routes a click to Actor 63. This used to reveal that model in the normal 144 px lane viewport. Neon intentionally uses a much shorter viewport, with drawing and audio lanes still below the model rows. The actual screenshot shows Ink and Audio at the content end, while the last model is above the visible area. Camera mode's focus helper does not schedule a model/layer scroll in this case, so the source mechanism is the shortened viewport and the test's content-end assumption, not an established auto-scroll race or input-routing defect.

For 64 collapsed model rows and two drawing layers, `timeline_view.gd` computes content height as `64*26 + 2*30 + 5 + 30 + 6 = 1765`. Actor 63's click center is `63*26+12 = 1650`. At the maximum scroll, the point is inside only when the viewport is at least 115 px high. The actual neon viewport is shorter. A 56 px viewport places it 59 px above the top. The approved compact layout should remain intact.
